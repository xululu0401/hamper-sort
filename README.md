# 分一筐脏衣服（hamper-sort）

一筐脏衣服里有白的、深的、会掉色的，有能随便洗的、要轻柔的、要走羊毛程序的。把每样衣服几件、每件多重、什么颜色、最多能走什么程序、水温上限填进清单，算最少要洗几缸、每缸放哪几件、走什么程序、水温不超过多少、几点能全部洗完；再给出「开一个颜色开关 / 先留几件」这类能少洗一缸的改法。

- 单页静态应用：`index.html` + `core.js`（计算）+ `ui.js`（界面），不联网、不收集数据，清单只存在本机 localStorage。
- 规则：白和深不同缸，易掉色只和易掉色同缸，白+浅、浅+深由开关决定；一缸走缸里最温和的程序，干重不超过「额定 × 该程序装载比例」；先最少缸数，再最少「被迫降档」的重量。按颜色互不相容的组分开做分支定界，到步数上限会如实说没证明最少。
- 测试：`node --test tests/core.test.cjs`；独立 Python 参考实现 `tests/ref.py`（集合划分暴力穷举，件数 ≤ 8）生成 `tests/ref.json`（300 组）；`node tests/inject.cjs` 做注入测试。
- 默认数字是虚构示例；能装多少看洗衣机说明书，颜色程序按自己判断。
